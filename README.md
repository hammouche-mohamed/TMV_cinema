# TMV Cinemas 🎬

A modern, premium cinema booking and management platform designed for **TMV Cinemas, Algeria**.

The project aims to digitize the cinema experience by providing customers with an intuitive platform to explore movies, discover screening schedules, select their seats, and reserve tickets online.

## Project Vision

Transform the traditional cinema booking experience into a seamless digital journey, from discovering a movie to receiving a digital ticket.

## Core Features

- **Movie Discovery:** Browse currently showing and upcoming movies.
- **Movie Details:** Explore descriptions, trailers, genres, and screening information.
- **Screening Schedules:** Discover available dates, times, and screening rooms.
- **Interactive Seat Selection:** Visual seating maps with real-time seat availability.
- **Online Reservations:** Complete booking workflows and reservation management.
- **Digital Tickets:** QR-code-based tickets and booking confirmations.
- **Customer Accounts:** Google authentication, personal profiles, and booking history.
- **Admin Dashboard:** Manage movies, screenings, cinema rooms, seats, customers, and reservations.

## Development Status

Currently in the frontend prototyping phase.

The initial version focuses on building a fully interactive user interface using simulated data, without backend integration or real reservations.

Backend services, database integration, authentication, and payment functionality are planned for future development, subject to project requirements.

## Technology Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Lucide Icons

## Objective

Build a scalable, responsive, and user-friendly digital cinema platform that improves the movie discovery and ticket reservation experience for TMV Cinemas customers.
